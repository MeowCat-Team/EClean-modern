## 未发布

### 新增

- **配置预设与诊断**：提供彼此独立的 `normal`、`dev` 预设，支持 `/eclean config profile <normal|dev>`、只读的 `config validate`、`config diff`，以及展示默认值、世界覆盖和规则来源的 `config effective [世界名]`。
- **明确的匹配模式**：`drop.mode`、`living.mode` 支持 `remove-matching`（清理匹配项）和 `keep-matching`（保留匹配项）。密度清理新增独立的 `protectTamed`、`protectAllay`，默认均开启。
- **指定范围的命令**：支持 `/eclean clean all <世界名> [--preview]`、将 `--preview` 放在 `clean` 之后任意参数位置，以及 `/eclean trash open`。
- **清理审计详情**：记录来源、操作者、世界/范围、配置版本、耗时、实际删除数、删除失败数、跳过区块数和执行中断状态。共享同一次执行的并发请求只记录一次，预览不写入历史。
- **PlaceholderAPI 计数**：新增 `%eclean_total_removed_entities%` 和 `%eclean_last_removal_time%`，分别提供本次进程内累计实际删除的实体数和最近一次实际删除时间。

### 修复

- **清理范围与保护**：自动清理、手动命令、预览和密度菜单清理遵守对应模块开关、禁用世界、逐世界开关和保护规则。预览不再更新历史、计数、倒计时，不回收物品或广播清理结果。
- **物品回收**：保留堆叠数量、自定义名称、lore、附魔和持久化元数据；回收失败保留来源，删除来源失败撤回待提交的入库。不会再按翻译后的展示文案误删物品原有 lore。
- **菜单交互**：拦截不安全的拖拽/点击转移及无效槽位映射，修复分页、过期条目和自定义堆叠上限处理。搜索会话在库存关闭后仍有效，支持取消和超时，搜索输入不会进入公共聊天。
- **密度菜单删除**：先展示指定范围的预览，要求在 30 秒内确认。执行时重新检查配置与保护，只考虑预览中已有的实体，重复确认不会重复提交。
- **权限与传送反馈**：尊重显式拒绝的权限，菜单重新校验访问权限，跨世界统计菜单需要世界统计权限。传送等待真实异步结果，拒绝非有限或越界坐标，临时返回计时只在传送成功后开始。
- **调度与统计**：在所属区域访问区块，不加载已卸载区块，按预算分批扫描，取消或调度失败时结束待处理操作。统计失败不再发布部分缓存，已加载的空区块也计入统计。
- **配置重载**：拒绝格式错误、未知字段、无效范围、正则和 Cron；重载失败保留上次有效配置。旧配置先验证再迁移并保留备份，配置、profile 和语言共同发布，重载时重新应用相关服务设置。
- **消息与翻译**：普通消息参数转义，避免递归占位符替换，点击动作通过组件构造。缺失翻译或自定义占位符不兼容时逐键回退；时长使用配置语言，实体名称展示 Minecraft 翻译和精确 ID，并修正帮助与菜单中的歧义。

### 变更

- **命令语法**：`top` 参数位置固定为 `/eclean top <entity|chunk> [数量] [世界名]`。指定世界时必须先填写 1–100 的数量，例如 `/eclean top entity 10 123` 查询名为 `123` 的世界。未知世界会明确报错。
- **清理计数**：`last_drop`、`last_living`、`last_chunk` 表示最近完成的对应清理请求结果，全服请求汇总各世界结果。一组掉落物算一个实体；垃圾桶总量和清空审计使用物品件数。
- **历史语义**：保留最近 100 条记录；`history_count` 为当前保留条数，`last_clean_time` 为最近一次记录的执行结束时间，包含零删除或失败的执行；`last_removal_time` 只在实际删除实体后更新。
- **更新检查**：按 SemVer 比较版本，忽略草稿，正式版安装只提示正式版本，更新提示去重、失败提示限频。推荐使用 `advanced.update.enabled`，旧 `global.updateCheck: false` 仍可禁用检查。
- **内部结构**：平台无关代码拆至 `common`，服务端实现拆至 `paper`；共用命令与权限定义，平台适配器显式注入依赖，移除被替代的清理 Planner 和旧工具路径。
- **构建可复现性**：要求 JDK 25，Paper API 固定为 `26.1.2.build.74-stable`，提交 Gradle 依赖锁与 SHA-256 校验清单，校验 wrapper 下载，并将 CI Actions 固定到具体提交。

### 升级注意事项

- 根 `config.yml` 必须显式声明 `profile: normal` 或 `profile: dev`。两套预设不互相继承，切换会替换整套规则。请备份已有配置，并在应用变更前查看 `config validate`、`config diff` 和 `config effective` 的结果。
- 显式 `mode` 优先于旧 `blacklistMode`。空匹配列表配合 `remove-matching` 不删除任何对象，配合 `keep-matching` 会选择全部未受保护对象。密度清理现在默认保护驯服生物和悦灵。
- 跨世界统计菜单同时需要 `eclean.command.stats.gui` 和 `eclean.command.stats.world`；配置诊断与预设切换需要 `eclean.command.config`。
- 垃圾桶内容、清理历史/累计计数和临时返回位置仍保存在内存中，不跨重启保留。物品合入已有垃圾桶条目不会延长该条目的到期时间。
- 替换插件需要完整停服，Folia 不支持插件热卸载。

## 0.2.0

### 新增
- **垃圾桶物品堆叠**：相同的物品放进垃圾桶后会自动合并成一格，一格显示一种物品和它的总数量（比如泥土 × 2345），想放多少放多少，没有数量上限。
- **每格物品单独计时**：每格物品有独立的存活时间，到期后这一格自己消失，不影响其他物品；剩余时间直接显示在物品说明里。
- **新的统计指令**：`/eclean trash stats`（管理员可用）查看垃圾桶里每种物品的数量和剩余时间。
- **新的配置选项**：`trashcan.yml` 里新增了堆叠开关、排序方式、剩余时间显示三个选项，都带注释说明。

### 变更
- 垃圾桶不再受"54 格 × 每格 64 个"的限制，容量无限。
- 不再整桶定时清空，改为每格物品各自到期后单独消失。
- 物品说明里现在会显示总数量（可以超过 64）和剩余时间。

### 移除
- 移除了垃圾桶容量上限的设置（容量已经无限，旧配置里留着的这一项会被自动忽略）。
- 移除了"整桶即将清空"的全服提醒消息。
